# CSFC Detector v2.0 — Withdrawn Pending Publication

**Status:** This implementation and its documentation have been withdrawn from public disclosure, effective 2026-11-04.

> **Why:** This folder previously published CSFC v2.0's internal six-stage thresholds, stage-recovery percentages, and detection/routing logic — material that every published CSFC series part and the Unified Theory paper explicitly reserve as non-public ("exact trigger thresholds and routing logic are retained outside the public repository"). It was published here ahead of any CSFC v2.0 paper, and has been withdrawn.

**What's still public and canonical:**

- **CSFC Unified Theory v1.0** (the only published CSFC paper): [DOI 10.5281/zenodo.17309239](https://doi.org/10.5281/zenodo.17309239)
- **CSFC series (Parts 1–6)**: [`vulnerability-research/csfc-series/`](../../../vulnerability-research/csfc-series/)
- **Public educational demo** (generic pattern-awareness heuristics only, no private thresholds): [CSFC Pattern Explorer on Hugging Face](https://huggingface.co/spaces/Feirbrand/csfc-detector)

No six-stage model, threshold table, recovery-rate figures, or incident counts for CSFC v2.0 are published anywhere. A public CSFC v2.0 release, if and when one is issued, will carry its own DOI and its own governed disclosure scope.
